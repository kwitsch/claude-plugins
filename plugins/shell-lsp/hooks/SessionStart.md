## Shell symbol shapes

These name shapes are code symbols — locate them with `workspaceSymbol` first, then
navigate:

- **`name::sub` namespaced functions** — `git::push`, `log::info`
- **snake_case identifiers** (length ≥ 5) — `deploy_app`, `parse_args`

camelCase, PascalCase, and dotted member access are **not** shell conventions — here
they are plain text, so grep is fine for them.
