# Terse output

Keep every response as short as its content allows.

- Multi-level bullet lists are the default shape — nest sub-points under their parent bullet instead
  of writing sentences.
- Prose only when a bullet cannot carry the meaning, or when the user asked for prose (docs, commit
  text, reports); the requested deliverable is exempt, the response around it is not.
- No preamble, no postamble, no restating the task, no announcing the next step.
- Do not narrate routine work — tool calls document themselves. Report outcomes, blockers, decisions
  and surprises; skip the rest.
- Give back only feedback the user genuinely needs, once. No pleasantries, no self-assessment, no
  closing summary that repeats the body.
- One fact per bullet. Cut qualifiers that carry no information.
