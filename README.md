# claude-plugins

A [Claude Code](https://docs.claude.com/en/docs/claude-code/plugins) plugin marketplace.

## Install

```
/plugin marketplace add kwitsch/claude-plugins
```

## Plugins

| Plugin                                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [cc-knowledge](plugins/cc-knowledge/README.md)             | Lookup skill and curated reference files for authoring and configuring Claude Code, a read-only expert agent that replaces the built-in claude-code-guide, and skills to review (cc-review), author (cc-author), audit memory (memory-audit), compress (cc-compress), audit LSP coverage (lsp-audit), and run a full repository audit that can also generate a user-level init-dev-environment installer skill (repository-audit) of Claude Code components.                                                                                                  |
| [coding-toolbox](plugins/coding-toolbox/README.md)         | Enforces the Interaction axis and blocks non-UTF-8 file edits automatically, plus fresh-branch, fresh-pr, finish-pr, fresh-work, feature-development, debugging, bump-version and user-level rules-setup skills for a self-contained git/PR workflow.                                                                                                                                                                                                                                                                                                         |
| [universal-format](plugins/universal-format/README.md)     | Formats prettier languages (JS/TS/JSON/YAML/Markdown/CSS/SCSS/LESS/HTML/Vue/GraphQL/Shell/Java/PHP) in-process before the write with the prettier — and its bundled java/php/shell plugins — shipped inside the plugin, and Kotlin/Python/Go/Rust after it, honoring `.editorconfig`, `.prettierignore` and tool-native configs.                                                                                                                                                                                                                              |
| [universal-lint](plugins/universal-lint/README.md)         | Runs each language's standard linter (read-only) on just-written Shell/Java/Kotlin/JS-TS/Python/Go/YAML/Markdown/CSS/SCSS/PHP/Rust files after Write/Edit, surfacing findings for Claude to fix; TypeScript files also get a whole-project `tsc --noEmit` type-check.                                                                                                                                                                                                                                                                                         |
| [memory-enhancement](plugins/memory-enhancement/README.md) | A dream skill that consolidates this project's auto-memory files in four phases, a self-improvement skill that reflects on session efficiency, and a turn-end/session-start mods hook pair that nudges the next session to run a dream cycle.                                                                                                                                                                                                                                                                                                                 |
| [npm-automations](plugins/npm-automations/README.md)       | Runs an async lockfile-frozen install (npm/pnpm/yarn, picked by whichever lockfile is present) when a project is entered via EnterWorktree, and an async, dependency-scoped install whenever a package.json's dependencies actually change.                                                                                                                                                                                                                                                                                                                   |
| [taskflow](plugins/taskflow/README.md)                     | Spec-driven design & delivery pipeline: `/taskflow:build-task` orchestrates a design-to-spec workflow and a spec-driven-delivery workflow (wave-parallel implement in isolated worktrees, combined review, fix application, ship); `/taskflow:dispatch-task` hands a described task to a worktree-isolated background session (`sonnet`/`xhigh`) that runs that whole pipeline unattended; `/taskflow:changes-audit` runs the combined review standalone over a branch diff, with `--fix` to auto-apply findings (or an interactive multi-select otherwise).  |
| [rc-enhancement](plugins/rc-enhancement/README.md)         | SessionStart hook that injects one critical must-follow rule: all user interaction goes through AskUserQuestion — never end a turn with a plain-text question, and capture free-text answers via the tool's Other option alongside an Abort/Cancel option.                                                                                                                                                                                                                                                                                                    |
| [inline-headroom](plugins/inline-headroom/README.md)       | Headroom-style levers inside Claude Code as a mod: clamp-only effort routing after successful tool results, a detector-only CacheAligner that logs cache-hit drops, and a SmartCrusher with lossless compaction, cross-turn dedup, a dense line elider, a config compressor, an HTML extractor, log, search and diff compressors, a text crusher and a relevance split that shrink tool results before the model reads them (originals retrievable, custom workflow tags kept whole). Ships a host-wide SQLite storage MCP server for persistent plugin data. |
| [dprint](plugins/dprint/README.md)                         | Skill that checks for a minimum dprint version, installs or updates dprint after confirmation, and offers to create a .dprint.jsonc from existing style configs.                                                                                                                                                                                                                                                                                                                                                                                              |
| [jevfort](plugins/jevfort/README.md)                       | Lets TypeSafe Jev take routine steps, route effort, gate risky calls and check that work is done (port of nim-f/jev-pilot; endpoint from JEV_URL).                                                                                                                                                                                                                                                                                                                                                                                                            |

## Configure plugins

Plugins with configuration options can be configured via
`/plugin -> installed -> select plugin -> Configure options`.
